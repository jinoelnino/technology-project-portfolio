# Portfolio scope and attribution

This repository contains professional case studies and simplified conceptual diagrams. It does not distribute the commercial products described in those studies.

- Cezen Technologies work is identified in its employment/project context. Product names and third-party technologies retain their respective ownership.
- Source code, configurations, datasets, client identities, internal infrastructure details, production screenshots and operational logs are excluded.
- Development, prototype, pilot and deployed workflow descriptions have distinct meanings. A successful check in one environment does not imply universal readiness.
- Open-source platforms and evaluation projects are attributed to their upstream authors. Integration and customization work is distinguished from original platform authorship.
- Future examples should use fictional data and newly prepared diagrams. Quantitative claims should be included only when substantiated and suitable for public disclosure.
