# Cezen Protect security dashboard

Security dashboard customization and integration work based on established open-source infrastructure.

**Scope:** Platform customization context; no independent security certification claim.

## The problem

Security tooling needs an operator-facing experience that fits the surrounding environment while respecting the maintenance and attribution requirements of its upstream platform.

## Architecture and leadership contribution

- Worked within the Cezen Protect dashboard and security-platform project context.
- Contributed to dashboard customization and the surrounding deployment/integration work.
- Considered the separation between the dashboard platform and product-specific user experience.

## Architecture decisions

**Extend an existing platform.** The dashboard derives from OpenSearch Dashboards; underlying search and dashboard capabilities are attributed to their upstream contributors.

**Separate customization from product qualification.** A branded interface and integration work do not establish a new detection engine or compliance certification.

## Delivery and outcome

This project demonstrates experience adapting an existing security platform to an enterprise product context. The private implementation is not part of this portfolio.

## Platform landscape

OpenSearch Dashboards, containers and the Wazuh security ecosystem.
