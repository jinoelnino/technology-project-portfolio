# Personal projects and technical labs

Alongside enterprise platform work, I explore local applications, reading experiences, creative tools and civic ideas. The descriptions below summarize project scope; source snapshots and prototypes are not presented as production services.

## Reading and audio tools

| Project | Scope |
|---|---|
| LARK Web Reader | Synchronized audiobook reading for phones and computers |
| Desktop Audiobook Reader | Windows reading interface with synchronized text and highlighting |
| Audiobook Workflow | EPUB and audiobook alignment workflow for synchronized reading files |

These related projects explore the relationship between content preparation, synchronization data and the playback experience across devices.

## Local utilities and creative workflows

| Project | Scope |
|---|---|
| Artha Finance Control Centre | Local personal-finance application |
| Creative File Hub | Browsing creative files for design and photography |
| Design File Explorer | File scanning and an HTML-based explorer |
| Android Phone Backup | Windows-based helper for accessible Android files |
| Subject Media Crawler | Web interface for collecting media around a topic |
| Immich Review Scanner | Local GPU-assisted media review utility |

These are project and prototype summaries. Private libraries, personal financial records, documents and media collections are excluded.
